What this page controls
Screen size, viewing distance and display calibration are what let a stimulus keep its intended luminance, color and spatial properties on a different monitor. Set them here and every condition launched from this page inherits them. The sync dot — position, size, on-time and color — is set here as well, since it follows the photodiode and the recording system rather than the stimulus. This browser remembers all of this between visits; the session note is not remembered, since it names a subject.

What the stimulus is — spatial frequency, colors, timing, fixation, masking — belongs to the stimulus pages, and this page does not touch it.
